4. Kesimpulan

LULUS*

Seluruh 500 iterasi bidding (100 user × 5 loop) berhasil dieksekusi dengan 0% error pada Phase 2 WebSocket. Total error rate 0,12% (17 dari 13.900 request) berasal dari 2 endpoint Phase 1. Core bidding flow berjalan stabil di bawah batas toleransi 3 detik.

GET Catalog Membership (list) — 12% error  |  GET Catalog Membership (detail) — 5% error
Kedua endpoint mengembalikan HTTP 500 setelah ~20 detik di bawah beban looping. Perlu investigasi dari tim developer — kemungkinan DB connection pool habis akibat concurrent WebSocket yang tinggi.
GET Car Brands & GET Catalog Membership Location — 0% error namun avg response tinggi (1.301ms dan 1.474ms). P90 masing-masing 3.712ms dan 7.070ms. Perlu dipantau pada Stress Test.
Catatan positif: Dibandingkan run sebelumnya (kemarin), error rate turun drastis dari 6,47% → 0,12%. Server dalam kondisi fresh memberikan hasil jauh lebih baik. Temuan kemarin (HTTP 500 massal) terkonfirmasi sebagai dampak akumulasi beban sepanjang hari.
