1How Tests Are Executed

Each test runs two components simultaneously to reflect actual production conditions where users perform different activities at the same time.

Main Test

Simulates users performing the full bidding flow:
Login → Browse Catalog → Enter Auction Room → Place Bid → Receive Broadcast

AXOtherOperation (Background)

Simulates other users doing general activities such as browsing the catalog, checking the auction schedule, and viewing notifications — running in parallel to replicate real production load where not all users are actively bidding.

ⓘ Both components run at the same time throughout the entire duration of each test.
